How issues are raised

Issues are raised automatically from the DGR every time data changes: inverter output per kWp, site yield against the portfolio, outage minutes and fault codes, transformer readings, silica gel and MOG, submission gaps, and recurring problems written in Remarks (for example "VCB annunciator faulty", "grass cutting required", "SCADA not working"). An issue stays open while the DGR keeps showing it. "Since" is the first day of the current run, or the first remark in the selected range.

Connecting the DGR app

Inside the DGR app, open this page as dashboard/index.html?embed in the Insights tab and send rows with postMessage({type:'dgr-rows', rows}), or set window.DGR_CONFIG = { apiUrl: "/api/dgr" }. See README.md in the package.
